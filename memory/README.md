# Память проекта

Индекс долговременных знаний о репозитории. Два уровня:

- **Общепроектная память** (`memory/project-*.md`) — что верно для всего репозитория независимо от роли: архитектура, конвенции, домен, тулинг. Читают все агенты.
- **Ролевая память** (`memory/agents/<role>.md`) — персистентная память конкретного субагента из `.claude/agents/`: зона владения, инварианты, карта кода, уже принятые решения и уже пойманные грабли.

Правило работы с памятью:

1. Агент читает свой файл `memory/agents/<role>.md` **до** того, как трогать любой файл, и опирается на общепроектные `memory/project-*.md` по мере надобности.
2. После задачи агент **дописывает** долговременные выводы (новый инвариант, неочевидная связка, класс ошибки) в свой ролевой файл короткими датированными буллетами со ссылками на файлы. Только append — чужие записи не переписывать и не подчищать.
3. Исходники всегда важнее памяти. Если файл на диске противоречит записи — побеждает файл, а расхождение отмечается в отчёте.

## Общепроектная память

- [Архитектура проекта](project-architecture.md) — слои `src/`, граница `core ↔ modules`, контракт barrel-экспортов, алиас `@/` и роутинг, поток данных «ввод → стор → алгоритм → анимация», реестр сторов.
- [Конвенции кода](project-conventions.md) — kebab-case и суффиксы ролей, порядок блоков SFC, type-only props / `withDefaults` / `defineModel` (без `defineEmits`), типизация, Pinia setup-сторы, barrel'ы, стилизация, иконки, i18n, форматирование.
- [Домен: словарь визуализатора поиска пути](project-domain.md) — ячейка, доска, восемь алгоритмов и их флаги, прогон и анимация, лабиринты, инструменты рисования, мёртвый код домена.
- [Тулинг: сборка, линт, формат, типы](project-tooling.md) — скрипты `package.json` дословно, что ловит каждый гейт, конфиги oxlint и oxfmt, TypeScript, Vite, Tailwind v4, `vite-svg-loader`, отсутствие тестов, порядок проверки перед сдачей.

## Ролевая память

- [algorithm-engineer](agents/algorithm-engineer.md) — `algorithms/`, `utils/`, `stores/`, `types/` модуля board: контракт `PathfindingAlgorithm`, синхронный чистый `run`, состав `PathfindingResult`, проходимость и соседи, стоимость шага.
- [i18n-keeper](agents/i18n-keeper.md) — `src/core/i18n/` и локаль-префиксный роутинг: паритет ключей `ru.ts` / `en.ts` (type-check его не ловит), плоские camelCase-ключи, смена локали только через роутер, `SUPPORTED_LOCALES` как единственный источник правды.
- [vue-builder](agents/vue-builder.md) — компоненты `src/core/components/` и `src/modules/board/components/`, composables, стили: `<script setup lang="ts">`, type-only props, `defineModel` вместо `defineEmits`, PascalCase-импорт / kebab-case в шаблоне.
- [project-reviewer](agents/project-reviewer.md) — читающая роль по всему `src/`, корневым конфигам, `AGENTS.md` и `memory/`: четыре проверочных гейта, замечания в терминах oxlint/oxfmt (не eslint/prettier), запрет требовать тесты.
